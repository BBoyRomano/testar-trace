# V1 scope

## Purpose

This document defines the intended V1 scope for ReqTrace.

## Included

V1 includes:

- canonical internal domain models
- canonical requirements input
- canonical state model input
- TESTAR JSON state model input
- analyzer selection
- baseline and alternative analyzers
- JSON export
- CLI entry point
- terminal UI
- SUT asset organization
- real-model execution on at least one SUT

## Excluded

V1 does not require:

- a web application
- database storage
- automatic requirements extraction from arbitrary documents
- automatic TESTAR protocol generation
- fully path-aware use-case traceability
- advanced report visualization
- broad multi-SUT evaluation coverage

## Success criteria

V1 is successful when ReqTrace can:

- load structured requirements
- load canonical and TESTAR state models
- run more than one analyzer on real TESTAR output
- produce coverage reports through the CLI
- export stable JSON reports
- preserve enough structure to support improved analyzers later
