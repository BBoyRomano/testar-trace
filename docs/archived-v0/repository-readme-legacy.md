# TESTAR Requirements Traceability (Legacy)

> Archived root README snapshot kept for historical context. The authoritative repository
> description is in the root `README.md`.

Repository accompanying the Master's thesis:
**Requirements Traceability for Scriptless GUI Testing**

This study develops and evaluates a method for tracing user stories to TESTAR-generated
GUI state models to assess user story execution completeness, thereby enabling
requirements coverage analysis for scriptless GUI testing.

## Repository Structure (Legacy Snapshot)

- [`../../docs/`](../../docs/) — Documentation and supporting materials
- `data/` — Legacy user stories and exported GUI state models (no longer present)
- `prototype/` — Legacy prototype implementation (no longer present)
- `evaluation/` — Legacy evaluation materials and results (no longer present)
- [`../../papers/`](../../papers/) — Research documents (LaTeX)
