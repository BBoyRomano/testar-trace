# TbUIS requirements source manifest

## Primary source pages
- Primary overview page: `https://projects.kiv.zcu.cz/tbuis/web/page/uis#use-cases`
- Secondary overview list: `https://projects.kiv.zcu.cz/uis/use-cases.jsp`
- Detailed use case pages: `https://projects.kiv.zcu.cz/tbuis/web/files/uis/uc/en/html/use-case-XX.html`

## Stored reference material
- `use-cases-reference.md`: source-faithful markdown capture of the original use-case catalog
- `diagrams/use-case-diagram.svg`: primary vector copy of the use-case diagram
- `diagrams/state-diagram.svg`: primary vector copy of the state diagram
- PNG diagram copies are kept only as convenience previews

## Canonical dataset policy
- `../canonical/tbuis-use-cases.json` is the authoritative structured dataset
- `../canonical/tbuis-use-cases.md` is the authoritative human-readable rendering
- `../execution/uc-*.md` files are generated execution inputs for the current markdown loader
