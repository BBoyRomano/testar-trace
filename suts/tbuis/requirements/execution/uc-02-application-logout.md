# Application logout
ID: UC.02
Actor: Logged in user

## Preconditions
- User is logged in - the right side of the upper bar displays the Logout option

## Main flow
1. User will click on the Logout option on the menu located on the right side of the upper bar
2. Background colour of the upper bar will change to black
3. Login Page will appear
4. Message confirming a successful execution will appear

## Postconditions
- Colour of the upper bar changes to black
- First and last names disappear from the upper bar menu
- Logout option disappears from the upper bar menu
- Login option appears in the right side of the upper bar
- Login Page page appears
- Message confirming a successful execution appears
