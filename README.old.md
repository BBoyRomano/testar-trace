# TESTAR Requirements Traceability

Repository accompanying the Master's thesis: **Requirements Traceability for Scriptless GUI Testing**

This study develops and evaluates a method for tracing user stories to TESTAR-generated GUI State Models to assess user story execution completeness, thereby enabling requirements coverage analysis for scriptless GUI testing.

## Repository Structure

- [`docs/`](docs/) — Documentation and supporting materials
- [`data/`](data/) — User stories and exported GUI State Models (JSON)
- [`prototype/`](prototype/) — Prototype implementation
- [`evaluation/`](evaluation/) — Evaluation materials and results
- [`papers/`](papers/) — Research documents (LaTeX)

## Related Project

This study uses TESTAR, an open-source tool for scriptless GUI testing:

- Source code: https://github.com/TESTARtool
- Website: https://testar.org/
