# ParaBank benchmark

This directory currently contains one TESTAR-generated ParaBank state-model
sample under `evidence/`. It does not yet contain the requirements, TESTAR
protocol/settings, generation metadata, or independently curated reference data
needed for a complete benchmark.

The captured state model includes content from the ParaBank demonstration
application. Its source, generation date, TESTAR version, applicable reuse
terms, and checksum must be documented before this artifact is used in a
published evaluation.
