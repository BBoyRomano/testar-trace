# Changelog

All notable changes to TESTAR Trace will be documented here. Published
distributions follow [Semantic Versioning](https://semver.org/). Before 1.0,
obsolete interfaces are removed instead of carrying compatibility layers.

## Unreleased

### Changed

- Reorganized the project around the `testar-trace`, `testar-trace-adapters`,
  CLI, web, documentation, and benchmark boundaries.
- Consolidated active architecture and product documentation under the TESTAR
  Trace name.
- Centered product terminology on requirements completeness; coverage remains
  a supporting diagnostic.

### Removed

- Removed archived implementations, obsolete interfaces, stale design copies,
  and generated legacy analysis results from the active repository layout.
- Removed deprecated CLI options and hidden compatibility commands.
